# ระบบแบบประเมินรายวิชา — คู่มือติดตั้ง

ไฟล์ในชุดนี้
- `Code.gs` — โค้ด Apps Script (ฐานข้อมูล Google Sheet)
- `index.html` — หน้าผู้ประเมิน (มือถือ)
- `admin.html` — หน้าแอดมิน + แดชบอร์ด
- `config.js` — ใส่ URL ของ Apps Script
- `common.js`, `style.css`, `qrcode.js` — ไฟล์ประกอบ

## 1) สร้างฐานข้อมูล (Google Sheet)
1. สร้าง Google Sheet ใหม่ ตั้งชื่อ เช่น “ประเมินรายวิชา ยุวกาชาด รุ่น 757”
2. เมนู **ส่วนขยาย › Apps Script** → ลบโค้ดเดิม วางโค้ดจาก `Code.gs` → บันทึก
3. เลือกฟังก์ชัน `setup` แล้วกด **เรียกใช้** (ครั้งแรกจะขอสิทธิ์ ให้กดอนุญาต)
   ระบบจะสร้าง 4 ชีต: ตั้งค่า · ข้อคำถาม · รายวิชา · ผลการประเมิน
4. แก้ข้อมูลในชีต
   - **ข้อคำถาม**: ใส่ข้อคำถามตามแบบฟอร์มของโรงเรียน
     ประเภท `scale` = 5 ระดับ, `text` = เขียนตอบ, `choice` = เลือกตอบ (ใส่ตัวเลือกคั่นด้วย ,)
     คอลัมน์ “ด้าน” ใช้จัดกลุ่มและคำนวณค่าเฉลี่ยรายด้าน
   - **รายวิชา**: รหัสวิชา (ห้ามซ้ำ) ลำดับ วัน เวลา ชื่อวิชา วิทยากร
   - **ตั้งค่า**: รหัสผ่านแอดมิน (adminPassword — ควรเปลี่ยน)
   - รายวิชา รหัสเข้าร่วม และจำนวนผู้เข้าอบรม แก้จากหน้าแอดมินแท็บ **จัดการข้อมูล** ได้ภายหลัง

> ⚠️ หลังเริ่มเก็บข้อมูลแล้ว อย่าเปลี่ยน “รหัส” ของข้อคำถามหรือวิชา (เปลี่ยนข้อความได้)

## 2) เปิดเป็น Web app
1. ใน Apps Script กด **การทำให้ใช้งานได้ › การทำให้ใช้งานได้รายการใหม่**
2. ประเภท: **เว็บแอป** · เรียกใช้ในฐานะ: **ฉัน** · ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
3. คัดลอก URL ที่ลงท้ายด้วย `/exec` ไปวางใน `config.js`
   ```js
   window.EVAL_API_URL = 'https://script.google.com/macros/s/.../exec';
   ```
> ถ้าแก้ `Code.gs` ภายหลัง ต้อง **จัดการการทำให้ใช้งานได้ › แก้ไข › เวอร์ชันใหม่** URL เดิมจึงจะได้โค้ดใหม่

## 3) ขึ้นเว็บด้วย GitHub Pages
1. สร้าง repository ใหม่ เช่น `eval757` แล้วอัปโหลดไฟล์ทั้งหมด (ยกเว้น `Code.gs` ก็ได้)
2. **Settings › Pages** → Source: `main` / root → Save
3. ลิงก์ผู้ประเมิน: `https://<ชื่อผู้ใช้>.github.io/eval757/`
   ลิงก์แอดมิน: `https://<ชื่อผู้ใช้>.github.io/eval757/admin.html`

## วิธีใช้ระหว่างอบรม
- สิ่งที่แก้จากหน้าแอดมินมีผลทันที ส่วนที่แก้ใน Google Sheet โดยตรงจะแสดงผลภายใน 20 วินาที (ระบบพักข้อมูลไว้เพื่อรองรับคนใช้พร้อมกันจำนวนมาก)
- ถ้ามีคนส่งพร้อมกันมาก ระบบจะลองส่งซ้ำให้อัตโนมัติ คำตอบไม่หาย
- กันประเมินซ้ำต่อเครื่อง: แนะนำให้ประกาศว่า “สแกน QR ด้วยกล้องมือถือ” (ไม่ใช้ LINE สแกน)
- แอดมินเข้า `admin.html` → แท็บ **เปิด-ปิดประเมิน** → เปิดสวิตช์วิชาที่เพิ่งจบ
- กด **แสดง QR เต็มจอ** ขึ้นจอโปรเจกเตอร์ ผู้เข้าอบรมสแกนแล้วประเมินได้ทันที (ค่าเริ่มต้นไม่ใช้รหัส ถ้าต้องการรหัสตั้งได้ในแท็บจัดการข้อมูล)
- แก้ชื่อวิชา วิทยากร วัน เวลา เพิ่ม/ลบ/เรียงวิชา ได้ในแท็บ **จัดการข้อมูล**
- ทั้งสองหน้ามีปุ่ม ☾/☀ สลับโหมดมืด/สว่าง
- ผู้ประเมินเห็นเฉพาะวิชาที่เปิด ประเมินได้ 1 ครั้งต่อวิชาต่อเครื่อง (ไม่เก็บชื่อ)
- แดชบอร์ดอัปเดตเองทุก 30 วินาที · ส่งออก CSV / พิมพ์รายงาน A4 ได้ในแท็บ **ส่งออก**

## ทดลองก่อนติดตั้ง
ถ้า `config.js` ยังว่าง ระบบจะเปิดในโหมดตัวอย่าง (ข้อมูลจำลอง)
รหัสผ่านแอดมิน `admin757`
